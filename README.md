Product Count Analysis

Project Overview
This project analyzes product counts across different categories using the Superstore dataset in Microsoft Excel.

Objective
- Count unique products in each category.
- Identify the category with the highest number of unique products.
- Practice Excel COUNTIF and COUNTIFS concepts.

Tools Used
- Microsoft Excel

 Key Finding
Office Supplies has the highest number of unique products, with 1,058 products.

 Deliverables
- Product Count Table
- Top Category Identification
- Excel Analysis Workbook

 Conclusion
This task helped me understand product categorization, unique product counting, and Excel-based data analysis.
